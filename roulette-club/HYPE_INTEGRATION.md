# Build Ways Duel Club: события, ачивки и рейтинг

Каждый игрок отправляет один собственный `run_end` в конце ВСЕЙ партии за столом.
Смерть участника, выстрел и новый раунд не заканчивают партию для телеметрии.
Соперники не получают победу владельца браузера: `won` сравнивает `winnerId`
с собственным сетевым id игрока, а не с фиксированным местом `p0`.

Поля: `won`, `runId` (= `matchId`), `mode: online|solo`, `abandoned`.
Ничья: `won: false, draw: true`. Явный выход из активного стола отмечается как отказ;
если клиент позже получит финал этого матча, отправится `won: false, abandoned: true`.
Ранний `run_end` при выходе запрещён: он закроет голос остальным участникам стола.
Временное переподключение не является поражением.
`score` и `depth` не отправляются: рейтинг здесь по победам, а не по локальным
бонусным очкам/сериям. Режим `?qa=1` не отправляет события и не меняет счётчики ачивок.

## Ачивки для регистрации в хабе

| id | Название | Условие для игрока | Уровень | Скрытая? | Иконка |
|---|---|---|---|---|---|
| `table_survivor` | Пережил стол | Выиграть партию | бронза | нет | стандартная хаба |
| `blank_self` | Пустой в себя | Выстрелить в себя холостым и сохранить ход | бронза | нет | стандартная хаба |
| `club_table` | Клубный стол | Завершить онлайн-партию с живыми игроками | бронза | нет | стандартная хаба |
| `full_chaos` | Полный хаос | Выиграть партию на четверых с дробовиком | серебро | нет | стандартная хаба |
| `five_online_wins` | Пять из пяти | Выиграть пять онлайн-партий подряд | золото | нет | стандартная хаба |

Соло-победы не увеличивают онлайн-серию. Поражение, ничья, явный выход или переход
с незавершённого онлайн-стола на новый сбрасывают серию. Повторные снимки состояния
и повторное получение одного результата не увеличивают её.

## Лидерборд

- Метрика: `won`, сумма побед за период по общим правилам из инструкции хаба.
- Учитываются реальные завершённые solo- и online-партии. Поле `mode` передаётся
  для аналитики; по инструкции собственные поля не меняют агрегацию рейтинга.
  Отдельный соревновательный рейтинг только против людей потребует фильтра в хабе.
- На партию у одного игрока 0 или 1 победа. Потолка суммы за неделю нет.
- Серверного POST нет; `runId` в клиентском событии не заменяет серверный `key`.
- Надёжный учёт закрытого приложения и защита результата требуют серверного API
  из `docs/HUB_EVENTS.md`. Текущие события из браузера не объявляются защищёнными.
  Результат вышедшего до конца игрока без повторного получения финала пока не отправляется.

Ключ облачного прогресса: `hub-events:roulette-club:v1`.
